What Twenty reads, and what it does not share

Twenty is a cue to pause when a conversation runs hot. It is not a health check. It does not diagnose, treat, or score anyone.

Read on this computer

  • The camera image, after you continue and start a room.
  • A pulse estimate. It is a 12-second average, and it can keep working while you talk.
  • A breathing estimate, used during the quiet pause to time a guide. Breathing is a poor guide while someone is talking, so the conversation itself watches pulse.

Stays here

  • The camera image. It is not recorded and not uploaded.
  • Pulse, breathing, and the calm minute Twenty uses as your own reference.
  • Which screen asked for the break. The other person is not told.

Can leave

  • The room code you share with the other person.
  • A random connection id, so the room can tell two computers apart. The other person is not shown it.
  • A yes or no: someone asked for a break.
  • A yes or no: you tapped “I’m ready”.

AI and other services

Twenty does not send your camera, pulse, or breathing to an AI service. It does not use ChatGPT, Claude, or any other chat model while it runs. It was written with help from Cursor, an AI coding agent. Cursor is not part of the running app, and the app does not send your camera, pulse, breathing, room, or API key to Cursor.

The measurement library is Presage SmartSpectra, running on this computer. It reads the camera here and estimates pulse and breathing here. Twenty turns off the library’s extra diagnostic reports. Twenty does not use Presage’s question feature, which would send a question and the measurements off this computer. The library still sends your API key to Presage so it is allowed to run. Presage’s documentation says that check is not an upload of the video or the numbers. Practice mode, with no key, does not start the library at all.

The room connection is not an AI service. By default it stays on this computer. It receives the room code, a random connection id that the other person is not shown, and yes or no for a break and for “I’m ready.” It does not receive pulse, breathing, or video.

What is saved, and for how long

Frames, pulse, breathing, and your calm minute stay in memory. They are not written to a file. Quit the app, or leave the room, and they are gone. If you paste an API key into the app, it is saved in this Mac’s private settings for Twenty until you remove it. If you put the key in a .env file yourself, it stays in that file until you delete the file. The room connection keeps the room code and the yes/no answers in memory only, and drops them when the last person leaves.

How to opt out

Close this window now and the camera never starts. After you continue, Stop camera and Leave room are on screen. Do not enter a shared room address if you want the room code to stay on this computer. Remove the saved key, or delete .env, to stop the Presage check. There is no switch that turns telemetry or an AI feature on. Twenty never turns them on.

No API key is loaded. You can still walk the screens with practice signals, or paste a key on the next screen. The key is not shown again.

The other person is a simulated recording, labeled the whole time. With an API key, your camera stays live. Without one, your side uses practice signals and the camera stays off.
